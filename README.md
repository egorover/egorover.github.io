# Резюме Александра Егорова — GitHub Pages

Статический одностраничный сайт резюме. Не требует сборки, серверной части или платных зависимостей.

## Содержимое

- `index.html` — страница резюме
- `styles.css` — адаптивные стили
- `assets/portrait.jpg` — фотография, извлечённая из исходного PDF
- `resume.pdf` — оригинал исходного резюме
- `resume-en.pdf` — английская версия резюме
- `README.md` — эта инструкция

## Публикация

1. Создайте публичный репозиторий `egorover.github.io` в аккаунте `egorover`.
2. Загрузите **содержимое** этого архива в корень репозитория (не сам ZIP-файл и не внешнюю папку).
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. В `Branch` выберите `main` и папку `/ (root)`, затем нажмите `Save`.
6. Дождитесь завершения публикации и откройте https://egorover.github.io/.

Публикация может занять несколько минут. Для обновления сайта достаточно загрузить изменённые файлы в корень репозитория.

## Важные замечания

- Контент перенесён из исходного резюме; формулировки адаптированы под веб-страницу без намеренного изменения смысла.
- Оригинальный PDF сохранён без изменений.
- Телефоны скрыты в раскрывающемся блоке, но доступны посетителю сайта после нажатия.
- Email, Telegram, GitHub и ссылки на проекты публичны.
- Внешние шрифты загружаются с Google Fonts; при недоступности сети используются системные шрифты.
- Перед публикацией проверьте актуальность публичных контактов и сведений, так как сайт и PDF будут доступны всем.
